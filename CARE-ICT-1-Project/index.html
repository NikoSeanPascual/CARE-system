Terms & Conditions & Privacy Notice

1. Data Processing and In-Memory Handling

Welcome to CARE: Campus Health, Medical Assessment, and Record Entry System. Please note that this system operates entirely using in-memory JavaScript data structures during active runtime session interaction.

2. No Persistent Web Storage

To comply with course guidelines and browser security standards, no personal health data, login credentials, or clinic records are stored permanently in browser localStorage or local persistent device storage.

3. Session Lifecycle

All entered student information, clinic check-in logs, queue numbers, and generated medical passes are stored temporarily for active session rendering. Closing or refreshing the browser page will instantly reset active queue entries and session data.

4. Scope of Use

The system is designed strictly for routine student health check-ins, symptom selections, and basic clinic visit summary generation within campus limits. It does not replace emergency medical response systems.

5. User Responsibilities

Students must provide accurate emergency contact details and truthful health information to assist clinic nurses and staff in delivering proper on-campus care.
